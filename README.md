# Gaussian Beam CNN Regression Pipeline

A synthetic-data pipeline for training a CNN to regress laser beam parameters
-- center coordinates `(x, y)` and spread widths `(sigma_x, sigma_y)` -- from
grayscale beam-profile images, then running that model on real camera
captures.

See [`docs/`](docs/) for architecture, dataset, model, and inference
details. This file only covers how to install and run the project.

## Requirements

- Python 3.9+
- See `requirements.txt`: numpy, pandas, pillow, opencv-python, torch,
  torchvision, matplotlib

## Setup (after cloning)

```bash
git clone git@github.com:AmanKumarBhamboo/gaussian-project.git
cd gaussian-project

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install --upgrade pip
pip install -r requirements.txt
```

That's it -- no dataset download, no external assets. Everything is
generated by code.

## Running the project

### Quick start -- one command

```bash
python3 main.py
```

With no arguments, `main.py` runs the full pipeline:

1. Checks whether a dataset already exists at `dataset/images` +
   `dataset/labels.csv`. If it's missing, it generates one (2,000 images).
   If it's already there, generation is skipped and the existing data is
   reused.
2. Trains all three CNN models (`tiny`, `medium`, `resnet18`), 30 epochs
   each by default, checkpointing the best validation-loss weights to
   `checkpoints/<model>_best.pt`.
3. Evaluates each trained model on the held-out test split and prints a
   summary table, followed by a closing footnote with next-step commands.

Re-running `python3 main.py` later will skip dataset generation (it's
already there) and just retrain the models from scratch.

### Full command reference

Every stage is also available as its own subcommand, for finer control:

```bash
# Generate the synthetic dataset (customize the per-category counts)
python3 main.py generate --normal 1500 --tilted 75 --noisy 250 --background 175

# Validate image integrity + label sanity
python3 main.py validate

# Save a preview grid image (few samples per category) for a visual sanity check
python3 main.py preview --output dataset/preview.png

# Train a single model
python3 main.py train --model medium --epochs 30

# Evaluate a trained checkpoint on a split
python3 main.py evaluate --model-path checkpoints/medium_best.pt --split test

# Run inference on a real (or synthetic) beam image
python3 main.py infer --image path/to/capture.png --model-path checkpoints/medium_best.pt

# Run the full generate-if-missing + train-all-models pipeline explicitly
python3 main.py all --models tiny medium resnet18 --epochs 30
```

Run `python3 main.py <subcommand> --help` for every flag on a given
subcommand (dataset paths, batch size, learning rate, etc. are all
overridable).
